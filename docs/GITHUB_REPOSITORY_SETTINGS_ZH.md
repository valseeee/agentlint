## 建议开启

- Issues；
- Discussions；
- Preserve this repository；
- Dependabot alerts；
- Secret scanning；
- Push protection；

- 自动删除已合并分支。

## main 分支保护

建议要求：

- Pull Request 后才能合并；
- CI / CodeQL / AgentLint 检查通过；
- 禁止强制推送；
- 禁止删除分支；
- 至少保留线性或可追踪提交历史。

## 高星项目首页重点

README 首屏应在几秒内回答：

1. 它解决什么问题；
2. 与现有工具有什么不同；
3. 如何 30 秒运行；
4. 有没有在线 Demo；
5. 有没有截图或 GIF；
6. 是否开源、是否需要 Token、源码是否上传。

发布后优先补充真实网页截图和 10～20 秒演示 GIF。不要使用夸张或无法验证的 Star 承诺。
