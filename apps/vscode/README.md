# AgentLint for VS Code

AgentLint validates `AGENTS.md`, `CLAUDE.md`, Cursor Rules, Copilot Instructions and other AI coding-agent guidance against the real repository.

## Features

- Chinese and English localization
- Workspace diagnostics and status-bar score
- Markdown report output and export
- Analyze on save
- Deterministic safe fixes

## Commands

- AgentLint: Analyze Workspace / AgentLint：分析工作区
- AgentLint: Clear Diagnostics / AgentLint：清除诊断
- AgentLint: Show Report / AgentLint：查看报告
- AgentLint: Export Markdown Report / AgentLint：导出 Markdown 报告
- AgentLint: Apply Safe Fixes / AgentLint：应用安全修复

Full documentation: `docs/VSCODE_EXTENSION_ZH.md` in the repository.
